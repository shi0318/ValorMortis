The current **Valor Mortis Demo PC requirements** on Steam are: Windows 11, a Ryzen 7 3700X or Intel i7-11700 processor, 16 GB RAM, an RX 6700 or RTX 2070 Super graphics card, DirectX 12, 20 GB of storage, and an SSD. The store explicitly says the specification can change for the final release. Checked August 12, 2026.

## Minimum requirements

| Component | Steam Demo listing |
| --- | --- |
| OS | Windows 11 |
| Processor | AMD Ryzen 7 3700X / Intel Core i7-11700 |
| Memory | 16 GB RAM |
| Graphics | AMD Radeon RX 6700 / Nvidia GeForce RTX 2070 Super |
| DirectX | Version 12 |
| Storage | 20 GB available space |
| Drive | SSD required |

The Steam page does not present a separate recommended configuration for the Demo in the current data checked here. Do not substitute the final game's future requirements for the Demo's current listing.

## What the SSD requirement means

An SSD is explicitly required by the Demo listing. Install the Demo to an SSD with more than the stated 20 GB free so Steam has room for updates and temporary files. The 20 GB figure is the published available-space requirement, not a promise that the installed folder will never change.

## Is the Demo free and where do I download it?

Yes. The official [Valor Mortis Demo Steam page](https://store.steampowered.com/app/4641840/Valor_Mortis_Demo/) lists the Demo as a free Steam product, App ID **4641840**, released June 7, 2026. The full game is a separate Steam product scheduled for October 13, 2026.

## Demo versus full release requirements

Steam currently lists the full game with a different, provisional specification and also notes that the Demo spec can change for the final release. Treat the two pages separately. A PC that meets the Demo listing should not automatically be described as meeting the final game's requirements.

## If the Demo will not launch

First verify Windows 11, 16 GB RAM, DirectX 12 support, the GPU class, and the SSD install location. Then update the graphics driver and verify the Steam files. These are general troubleshooting steps; this page does not claim a developer-confirmed fix for every launch issue.
