Everything on this page about platform, system requirements, and store features comes straight from the **official Steam pages** for Valor Mortis (App 2828710) and the Valor Mortis Demo (App 4641840), checked July 27, 2026. Where we suggest what to tune, that's labelled as advice rather than an official setting.

## Platform

Valor Mortis is listed for **Windows PC via Steam** only. The store page specifies a **64-bit** OS and **DirectX 12**. No console versions are listed on Steam as of the last check — if that changes, this page will be updated.

## Minimum system requirements

| Component | Minimum |
| --- | --- |
| OS | Windows 10 64-bit |
| Processor | Intel Core i5-8400 / AMD Ryzen 5 2600 |
| Memory | 16 GB RAM |
| Graphics | NVIDIA GeForce GTX 1070 / AMD Radeon RX 5600 XT |
| DirectX | Version 12 |
| Storage | 50 GB available space |

## Confirmed features and comfort options

From the Steam store categories:

- **Single-player**
- **Full controller support**, including **DualSense controller support**
- **Save Anytime** (listed specifically for the Demo)
- **Subtitle options**
- **Surround sound**
- **HDR available**

The **Save Anytime** feature is the standout for a soulslike Demo — it lets you stop and resume freely, which is genuinely useful for learning fights without pressure.

## What to check before you play (advice)

This section is practical guidance, not official instruction:

- **Update your GPU drivers.** DirectX 12 soulslikes are sensitive to driver versions.
- **Confirm you have 50 GB free.** That's the listed storage figure; leave headroom.
- **Try a controller if you have one.** With full DualSense support confirmed, a pad is a natural fit for parry-timing combat.
- **Turn on subtitles** if you want to follow the story in a noisy, atmospheric mix.
